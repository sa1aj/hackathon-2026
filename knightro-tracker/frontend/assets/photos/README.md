# Stock Knightro photos

The backend doesn't store images yet, so sightings show a stock photo.

1. Add photos here (JPG/WebP, about 800×600, under 200 KB each). Only use photos the team has the right to use.
2. List them in `STOCK_PHOTOS` in [`../../js/config.js`](../../js/config.js), e.g. `'assets/photos/knightro-1.jpg'`.

Each sighting always gets the same photo from the list. While the list is empty, a pixel-art illustration is shown.
